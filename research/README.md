# Research

Здесь хранятся полезные для проекта исследования: анализ платформы и данных, идеи функций, результаты общения с заказчиком, требования и экономические расчёты.

Структура внутри каталога создаётся по мере появления реальных материалов. Каждый документ должен отделять подтверждённые факты от гипотез и содержать ссылки на источники или входные данные.
