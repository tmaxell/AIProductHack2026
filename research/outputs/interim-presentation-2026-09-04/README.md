# Промежуточная презентация — 04.09.2026

Слайдовая презентация текущего состояния проекта для обязательной промежуточной сдачи 04.09.2026 в 10:00.

## Файлы

- `interim-presentation.pptx` — сам файл презентации, 9 слайдов, 16:9.
- `build-deck.js` — скрипт, который её собирает.

## Состав слайдов

1. Титул.
2. Проблематика: текущий процесс и его стоимость.
3. Постановка задачи и целевые метрики.
4. Выбранный подход: двухэтапная валидация.
5. Схема решения: поток данных, детерминированное ядро, AI-слой и guardrails.
6. Выполненные этапы и первые результаты.
7. Unit-экономика и гипотеза упаковки.
8. Основные риски и план работ до финальной защиты.
9. Команда: роли, зоны ответственности и текущая степень участия.

## Как пересобрать

```bash
npm install pptxgenjs
node build-deck.js interim-presentation.pptx
```

Скрипт не входит в состав решения и не добавляет зависимостей в `solution/`: `pptxgenjs` ставится разово в окружении того, кто пересобирает файл. Проверено на `pptxgenjs` 4.0.1.

Правки вносим в `build-deck.js` и пересобираем, а не редактируем `.pptx` вручную: иначе следующая пересборка их затрёт. Если файл всё же правился в PowerPoint, сначала перенесите изменения в скрипт.
