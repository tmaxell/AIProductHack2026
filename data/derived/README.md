# Производные данные

Содержимое этого каталога по умолчанию не коммитится. Каждый результат должен воспроизводиться из `data/raw/` и иметь:

- скрипт или ноутбук преобразования;
- версию/хэш входа;
- описание схемы;
- проверки качества;
- объяснение, почему результат нужно хранить.

Если небольшой производный файл необходим для тестов или eval, добавьте точечное исключение в `.gitignore` и документируйте его здесь.
