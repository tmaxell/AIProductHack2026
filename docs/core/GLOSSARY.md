# Глоссарий

| Термин | Определение в проекте |
|---|---|
| Заявка | Необработанная или изменённая проектная инициатива во входящей таблице. |
| Проект | Подготовленная к запуску сущность со связанной компанией, типом, сроками, бюджетом и задачами. |
| Дубль | Заявка или справочная запись, относящаяся к той же реальной сущности/инициативе, что и другая запись. |
| Matching | Сопоставление заявки с канонической записью справочника. |
| Нормализация | Приведение представления значения к сравнимой форме без потери исходного значения. |
| Рекомендация | Предлагаемое изменение или связь с причиной, confidence и статусом подтверждения. |
| Confidence | Калиброванная оценка уверенности алгоритма, а не обещание истинности. |
| Preview | Представление `было → станет` до изменения данных. |
| Идемпотентность | Повторный запуск с тем же входом не создаёт новых дубликатов или лишних изменений. |
| Core | Стабильный контракт: подтверждённые цели, ограничения и принципы. |
| Working artifact | Изменяемый исследовательский или проектный документ, который не переопределяет core. |
| ADR | Запись важного решения с контекстом, альтернативами и последствиями. |
