# Solution

Здесь разрабатывается фактическое решение для MWS Tables: исходный код Widget Script, тесты, конфигурация и техническая инструкция по установке.

Технологическая структура будет добавлена после проверки возможностей Script Widget и выбора способа разработки. Требования и ограничения решения находятся в [`docs/core/PROJECT.md`](../docs/core/PROJECT.md).
