# Отчёты тестовых прогонов

Сюда `run-local.js` пишет по одному markdown-файлу на каждый запуск (`run-<таймстамп>.md`): seed, режим, `--limit`, длительность, итоговые счётчики виджета. Файлы не перезаписываются — история прогонов накапливается.

Это сырые, генерируемые артефакты одного конкретного запуска (см. `AGENTS.md`: генерируемый мусор не коммитим) — не коммитятся, кроме этого README. Curated-сводка по каждому milestone (с найденными багами и выводами) — в [`../../docs/TEST-RESULTS.md`](../../docs/TEST-RESULTS.md).
