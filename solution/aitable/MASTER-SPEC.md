# MWS Tables — Набор виджетов нормализации данных

## Обзор

Набор инструментов для очистки, нормализации и анализа данных в таблицах MWS/AITable.

**Структура:**
```
aitable/
├── mini_widgets/     # 8 автономных виджетов для точечной обработки
├── big_widget/       # 2 мастер-скрипта для комплексной обработки
├── WIDGET-TEMPLATE.md # Шаблон для создания новых виджетов
└── MASTER-SPEC.md    # Этот файл — общая спецификация
```

---

## 📦 Mini Widgets (8 виджетов)

Набор из 8 независимых скриптов. Каждый решает одну задачу.

| # | Виджет | Назначение | Строк |
|---|--------|------------|-------|
| 01 | `01-normalize-basic.js` | Базовая нормализация (ё→е, пробелы, кавычки, тире) | ~240 |
| 02 | `02-normalize-emails.js` | Email (нижний регистр, mailto:, валидация) | ~230 |
| 03 | `03-normalize-phones.js` | Телефоны (+7XXXXXXXXXX, маскированные→флаг) | ~280 |
| 04 | `04-normalize-dates.js` | Даты (ISO YYYY-MM-DD, 4 формата) | ~300 |
| 05 | `05-normalize-fio.js` | ФИО (Title Case, инициалы, 2-3 части) | ~280 |
| 06 | `06-normalize-cities.js` | Города (алиасы, г→"", латиница→флаг) | ~260 |
| 07 | `07-normalize-companies.js` | Компании (убрать ООО/ИП, кавычки) | ~180 |
| 08 | `08-normalize-amounts.js` | Суммы (млн/тыс/руб, числа) | ~210 |

**Общие свойства:**
- ✅ **Автономные** — все функции внутри, нет внешних зависимостей
- ✅ **Умная детекция** — сами находят поля по названию и содержимому
- ✅ **Preview** — показывают первые 15 изменений перед применением
- ✅ **Партиционное применение** — по 100 записей с прогрессом
- ✅ **Флаги проблем** — помечают проблемные значения для ручной проверки

**Документация:**
- [`README-WIDGETS.md`](mini_widgets/README-WIDGETS.md) — полная спецификация
- [`CHEATSHEET.md`](mini_widgets/CHEATSHEET.md) — шпаргалка для быстрого старта

## 🚀 Big Widget (2 мастер-скрипта)

Комплексные скрипты для полной обработки данных.

### Lite версия (рекомендуется)

**Файл:** `big_widget/script-project-launch-copilot-lite.js`

**3 шага:**
1. **Настройка** — выбор полей
2. **Анализ и нормализация** — 8 типов данных + preview → apply
3. **Поиск дублей** — авто-ключи (email/телефон/ИНН) или ручной выбор
4. **Интеллект** — топ-10 правил очистки с рекомендациями

**Преимущества:**
- ✅ Проще (3 шага вместо 5)
- ✅ Быстрее (нет запросов к справочникам)
- ✅ Умный поиск дублей (ручной выбор ключей)
- ✅ Автономная (не зависит от других таблиц)

**Когда использовать:**
- Быстрая очистка одной таблицы
- Нет справочников в пространстве
- Нужен только поиск дублей и нормализация

**Документация:** [`SPEC-COPILOT-LITE.md`](big_widget/SPEC-COPILOT-LITE.md)

---

### Полная версия

**Файл:** `big_widget/script-project-launch-copilot.js`

**5 шагов:**
1. **Настройка источников** — выбор таблиц и справочников
2. **Анализ и нормализация** — 8 типов данных
3. **Поиск дублей и сопоставление** — matching со справочником компаний
4. **Запуск проекта** — создание задач по шаблону + round-robin
5. **Интеллект** — анализ правил очистки

**Когда использовать:**
- Есть справочники (компании, сотрудники, шаблоны)
- Нужно создание задач по шаблону
- Нужен matching со справочником компаний
- Полный запуск проекта «под ключ»

```

```

```

```

```
2. Шаг 1: Выбрать справочники (компании, сотрудники, шаблоны)
3. Шаг 2-3: Нормализация и дубли
4. Шаг 4: Выбрать шаблон → создать задачи → round-robin
5. Шаг 5: Анализ правил
Время: ~15 минут
```

## 🔧 Как использовать

### Запуск виджета

1. **Открыть таблицу** в MWS Tables
2. **Добавить виджет** «Скрипт»
3. **Вставить код** из файла (скопировать полностью)
4. **Нажать** «Выполнить»
5. **Следовать инструкциям** в чате

### Выбор версии

**Начни с Mini Widgets, если:**
- Нужно очистить один тип данных (только email, только телефоны)
- Хочешь контролировать каждый шаг отдельно
- Таблица небольшая (< 500 строк)

**Используй Copilot Lite, если:**
- Нужно очистить все данные сразу
- Нет справочников в пространстве
- Хочешь найти дубли
- Нужен анализ правил

**Используй Copilot Full, если:**
- Есть справочники (компании, сотрудники, шаблоны)
- Нужно создать задачи по шаблону
- Нужен matching со справочником
- Запускаешь проект «под ключ»

## 📋 Правила нормализации

### 01 — Базовая
- Ё → Е (Ковалёва → Ковалева)
- Неразрывные пробелы → обычные
- Табы, переносы → пробелы
- Кавычки «»"" → ""
- Тире –— → дефис -
- Множественные пробелы → один

### 02 — Email
- TEST@EXAMPLE.COM → test@example.com
- mailto:test@example.com → test@example.com
- Убирает пробелы и ;

### 03 — Телефоны
- 89991234567 → +79991234567
- 9991234567 → +79991234567
- Маскированные ***1234 → флаг

### 04 — Даты
- 15.01.2024 → 2024-01-15
- 15.01.24 → 2024-01-15
- 15 января 2024 → 2024-01-15

### 05 — ФИО
- иванов иван → Иванов Иван
- ИВАНОВ ИВАН → Иванов Иван
- Инициалы И.И. → сохраняет

### 06 — Города
- екб → Екатеринбург
- мск → Москва
- г Москва → Москва

### 07 — Компании
- ООО "Ромашка" → Ромашка
- ИП Иванов → Иванов

### 08 — Суммы
- 1.5 млн → 1500000
- 150 тыс → 150000
- 1000 руб → 1000

## ⚠️ Ограничения

- API MWS Tables не позволяет скриптам создавать столбцы
- Максимальный размер партиции: 100 записей
- Визуальный режим (со столбцами _OLD/_NEW) требует ручного создания столбцов
