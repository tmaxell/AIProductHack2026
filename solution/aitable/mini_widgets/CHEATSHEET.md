# 🚀 Шпаргалка по виджетам нормализации

## 8 виджетов для очистки данных

| # | Что делает | Пример |
|---|------------|--------|
| **01** | Базовая: ё→е, пробелы, кавычки | Ковалёва → Ковалева |
| **02** | Email: нижний регистр, mailto: | TEST@EXAMPLE.COM → test@example.com |
| **03** | Телефоны: +7, 10-12 цифр | 89991234567 → +79991234567 |
| **04** | Даты: ISO формат | 15.01.2024 → 2024-01-15 |
| **05** | ФИО: Title Case | иванов иван → Иванов Иван |
| **06** | Города: алиасы, г→"" | екб → Екатеринбург |
| **07** | Компании: без ООО, ИП | ООО "Ромашка" → Ромашка |
| **08** | Суммы: млн, тыс, руб | 1.5 млн → 1500000 |

---

## Как запустить (3 шага)

1. **Открыть таблицу** → виджет «Скрипт»
2. **Вставить код** из файла (например, `01-normalize-basic.js`)
3. **Нажать «Выполнить»** → следовать инструкциям в чате

---

## Рекомендуемый порядок

```
#01 → #02 → #03 → #04 → #05 → #06 → #07 → #08
```

Или выбрать только нужные.

---

## Что видит пользователь в чате

```markdown
# 🔤 Виджет #01: Базовая нормализация
Таблица: **Моя таблица**

## Что делает этот виджет:
- Ё → Е (Ковалёва → Ковалева)
- Неразрывные пробелы → обычные
- Кавычки «» → ""
- Тире — → дефис -
- Множественные пробелы → один

## Шаг 1. Выбор полей
Найдено текстовых полей: 10
...
```

---

## Флаги проблемных данных

Виджет помечает проблемные значения → нужно проверить вручную:

- ❌ `некорректный email`
- ❌ `номер маскирован` (***1234)
- ❌ `<10 цифр` или `>12 цифр`
- ❌ `формат даты`
- ❌ `латиница` (для городов)
- ❌ `не сумма`

---

## Советы

✅ **Начать с #01** — почистит базовый "мусор" для лучших результатов остальных

✅ **Использовать умную детекцию** — виджеты сами найдут нужные поля

✅ **Проверить preview** — перед применением посмотреть первые 15 изменений

⚠️ **Важные данные** — использовать визуальный режим (требует создания столбцов _OLD, _NEW, _APPLY)

## Примеры

### Быстрая очистка (1000 строк)
```
Запустить: #01 → #02 → #03
Время: ~5 минут
```

### Тщательная проверка (100 строк)
```
1. Создать столбцы (_OLD, _NEW, _APPLY)
2. Запустить #01-visual
3. Проверить в таблице
4. Ввести "готово"
Время: ~15 минут
```

### Только критичные поля
```
Запустить: #06 (Города) + #07 (Компании)
```
