# Project Launch Copilot Lite — Спецификация

## Обзор

Упрощённая версия скрипта для нормализации данных и поиска дублей в MWS/AITable.

**Версия:** Lite (без справочников и создания задач)  
**Файл:** `script-project-launch-copilot-lite.js`  
**Строк кода:** ~450

---

## Отличия от полной версии

| Полная версия | Lite версия |
|---------------|-------------|
| 5 шагов | 3 шага |
| Справочники (компании, сотрудники, шаблоны, задачи) | ❌ Нет справочников |
| Запуск проекта по шаблону | ❌ Нет создания задач |
| Matching со справочником компаний | ❌ Нет matching |
| ✅ Нормализация | ✅ Нормализация |
| ✅ Поиск дублей | ✅ Поиск дублей (улучшенный) |
| ✅ Интеллект (анализ правил) | ✅ Интеллект |

---

## 3 шага работы

### Шаг 1. Настройка

**Что делает:**
- Выбор представления (опционально)
- Выбор текстовых полей для обработки
- Исключение полей по названию

**Пользователь:**
- Видит список всех текстовых полей
- Может исключить поля по названию (через запятую)
- Подтверждает выбор

---

### Шаг 2. Анализ и нормализация

**Что делает:**
- Авто-детекция типа поля (email, телефон, дата, ФИО, город, компания, сумма)
- Нормализация по правилам
- Сбор изменений и проблемных записей
- Preview (первые 15 изменений)
- Применение после подтверждения

**Правила нормализации:**

| Тип | Правила |
|-----|---------|
| **Базовая** | Ё→Е, кавычки, пробелы, тире |
| **Email** | нижний регистр, mailto:, валидация |
| **Телефон** | +7XXXXXXXXXX, маскированные→флаг |
| **Дата** | YYYY-MM-DD, валидация |
| **ФИО** | Title Case, инициалы, 2-3 части |
| **Город** | алиасы (екб→Екатеринбург), г→"" |
| **Компания** | убрать ОПФ (ООО, ИП), кавычки |
| **Сумма** | млн→*1e6, тыс→*1e3, руб→"" |

**Пользователь:**
- Видит preview изменений
- Вводит "да" для применения
- Получает отчёт о применении

---

### Шаг 3. Поиск дублей

**Что делает:**
- Авто-детекция полей для ключей (email, телефон, ИНН, название, ФИО)
- Предлагает авто-ключи или ручной ввод
- Строит fingerprint по комбинации ключей
- Группирует дубли
- Показывает таблицу дублей

**Умная детекция ключей:**

| Поле | Ключ |
|------|------|
| `email` (тип email) | нормализованный email |
| `phone` (тип phone) | нормализованный телефон |
| `ИНН` (по названию) | цифры ИНН (10+) |
| `company` (тип company) | нормализованное название |
| `fio` (тип fio) | нормализованное ФИО |

**Пользователь:**
- Видит авто-найденные ключи
- Может выбрать "да" (использовать авто) или ввести названия полей вручную
- Получает таблицу дублей (первые 15 групп)

**Пример:**
```
Авто-ключи: email (email), phone (телефон), ИНН (ИНН)

Использовать авто-ключи (да) или ввести вручную?
> да

Найдено групп дублей: 5

| Ключ                  | Строки      | Записей |
|-----------------------|-------------|---------|
| test@example.com|+7999| 1, 5, 12   | 3       |
| 7771234567            | 3, 8        | 2       |
```

---

### Шаг 4. Интеллект

**Что делает:**
- Анализирует частоту применённых правил
- Строит топ-10 правил
- Даёт рекомендации (🔁 повторять / 💡 опционально)

**Рекомендации:**
- **🔁 повторять** — правило применено ≥5% записей (стоит использовать в будущем)
- **💡 опционально** — правило применено <5% (можно не использовать)

**Пользователь:**
- Видит таблицу топ-правил
- Понимает, какие правила наиболее полезны для этой таблицы

## Как использовать

### Запуск

1. Открыть таблицу в MWS Tables
2. Добавить виджет «Скрипт»
3. Вставить код из `script-project-launch-copilot-lite.js`
4. Нажать «Выполнить»
5. Следовать инструкциям в чате

### Когда использовать

**Lite версия:**
- ✅ Быстрая очистка одной таблицы
- ✅ Нет справочников в пространстве
- ✅ Нужен только поиск дублей и нормализация
- ✅ Тестирование перед запуском полной версии

**Полная версия:**
- ✅ Есть справочники (компании, сотрудники, шаблоны)
- ✅ Нужно создание задач по шаблону
- ✅ Нужен matching со справочником компаний
- ✅ Полный запуск проекта

---

## Ограничения

- ❌ Нет работы со справочниками
- ❌ Нет создания задач
- ❌ Нет matching со справочником компаний
- ❌ Нет round-robin распределения

---

## Преимущества

- ✅ Проще (3 шага вместо 5)
- ✅ Быстрее (нет запросов к справочникам)
- ✅ Улучшенный поиск дублей (ручной выбор ключей)
- ✅ Автономная (не зависит от других таблиц)
