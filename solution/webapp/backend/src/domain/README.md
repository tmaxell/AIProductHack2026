# domain

Слой чистой доменной логики: без Fastify, без HTTP, без переменных окружения.
Функции принимают данные и возвращают данные, поэтому их можно тестировать
изолированно и переиспользовать вне веб-приложения.

Каталог намеренно пуст: логика проверки пока живёт на фронтенде
(`solution/webapp/frontend/public/widget-script.js`) и переносится сюда
отдельной задачей. Контракт того, что должно появиться, уже зафиксирован в
[`../contracts/validation.ts`](../contracts/validation.ts), а эндпоинт
`POST /api/v1/validation/runs` отвечает `501 Not Implemented`, пока переноса нет.

Граница: сюда **не** переносится код Widget Script для реальных MWS Tables
(`solution/src/`). Это отдельный трек, см. [`../../README.md`](../../README.md).
