# Frontend веб-приложения Project Launch Copilot

Статический фронтенд: оболочка в визуальной грамматике MWS Tables и панель
виджета, которая показывает предложенные изменения и даёт подтвердить или
отклонить каждое из них до записи данных.

Правил нормализации здесь нет: они живут в backend
([`solution/webapp/backend/src/domain/`](../../backend/src/domain/README.md)),
а фронтенд ходит в него через [`api.js`](api.js) и не повторяет серверные правила.

Это mock оболочки MWS Tables, а не установленный Widget Script. Решение,
встраиваемое в реальные MWS Tables, — отдельный трек, граница описана в
[`solution/README.md`](../../../README.md).

## Запуск

Фронтенду нужен backend, поэтому штатный способ — весь стек в Docker:

```bash
cd solution/webapp && make up
```

Приложение — <http://127.0.0.1:8080>. Открытые как файлы `index.html` работать
не будет: запросы к `/api/v1` уходят через nginx.

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка оболочки, панели виджета, отчёта и набор inline SVG-иконок |
| `styles.css` | Визуальная система: токены, оболочка, таблица, состояния виджета |
| `app.js` | Состояния виджета, таблица, решения пользователя по действиям |
| `api.js` | Единственное место, где фронтенд знает про HTTP |
| `data.js` | 30 записей типа APPLICATION из `data/raw/dev-sample.csv` |

## Сценарий

1. **Выбор области.** Без отметок проверяются все записи. Отмеченные строки
   сужают область: панель показывает «Выбранные записи», непроверенные строки
   остаются со статусом «Не проверено».
2. **Проверка.** `POST /api/v1/change-sets` возвращает черновик набора
   изменений. Ничего не записывается.
3. **Решения.** В отчёте у каждого действия свой чекбокс, в шапке таблицы —
   переключатель всего правила. Панель и футер показывают «Подтверждено N из M».
4. **Применение.** `POST /api/v1/change-sets/apply` применяет **только**
   подтверждённые действия. Отклонённые остаются нетронутыми.
5. **Итог.** Панель показывает применённые изменения по правилам и пропущенные
   действия. Кнопка «Отменить изменения» возвращает исходные значения.

Данные живут в памяти страницы: перезагрузка возвращает исходную выборку.

## Что действительно работает

Интерактивны только перечисленные элементы. Проводник, rail и кнопки вида в
toolbar статичны и намеренно не выглядят кликабельными.

- поиск по названию проекта, компании, городу, ИНН, id заявки и email;
- отметка строк — задаёт область проверки;
- «Проверить данные», «Посмотреть изменения», «Применить N», «Отменить изменения»;
- чекбокс на каждом действии и на правиле целиком;
- сворачивание панели виджета и возврат вертикальной кнопкой у правого края;
- отчёт закрывается по Escape, Tab и Shift+Tab не выходят за его пределы.

## Состояния виджета

| Состояние | Что показывает |
|---|---|
| До запуска | источник или число выбранных записей, один CTA «Проверить данные» |
| Выполняется | спиннер и disabled-кнопка |
| Результат | `30 записей · 168 предложений`, три строки счётчиков, «Подтверждено N из M» |
| Применено | что изменено по правилам, пропущенные действия, «Отменить изменения» |
| Ошибка | причина и «Повторить»; запрос не висит дольше 20 секунд |

## Ожидаемый результат на текущих 30 записях

| Правило | Изменений |
|---------|-----------|
| Email компании | 23 |
| Телефон компании | 24 |
| ИНН компании | 20 |
| Город | 9 |
| ФИО заявителя | 17 |
| Бюджет | 24 |
| Дата начала | 27 |
| Дата окончания | 24 |

Итого 168 предложений, 12 замечаний уровня `info` (город латиницей, кириллический
вариант неизвестен), 0 блокирующих ошибок. Повторная проверка после применения
предлагает 0 изменений: сценарий идемпотентен.

## Чего пока нет

Не реализованы обязательные части сквозного сценария из
[`docs/core/PROJECT.md`](../../../../docs/core/PROJECT.md): поиск дублей,
matching со справочниками и confidence, создание связей, выбор шаблона проекта,
создание задач, рекомендации исполнителей и итоговый отчёт запуска.

Также нет версий набора изменений, публикации и rollback: они требуют
хранилища, а это решение принимается отдельным ADR. Отмена сейчас работает
только в памяти страницы.
