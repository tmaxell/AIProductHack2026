# AGENTS.md

## Контекст

Репозиторий содержит знания и реализацию хакатонного проекта по автоматизации подготовки проектов в MWS Tables.

Перед работой прочитай `README.md`, `docs/core/PROJECT.md`, `STATUS.md` и ближайший `README.md` в изменяемом каталоге. Проверь `git status` и не перезаписывай чужие незавершённые изменения.

## Правила

- Не придумывай требования и результаты интервью. Отделяй подтверждённые факты от гипотез и указывай источники.
- Не изменяй файлы в `data/raw/`. Для данных дополнительно действует `data/AGENTS.md`.
- Исследования, идеи, интервью, требования и расчёты сохраняй в `research/` по мере их появления, без заранее придуманной процессной иерархии.
- Код, тесты и техническую документацию продукта размещай в `solution/`.
- В `solution/` два независимых трека, и они не смешиваются: встраиваемый Widget Script (`solution/src`, `build`, `devtools`, `dist`, `plan`, `docs`) и самостоятельное веб-приложение (`solution/webapp/`). Не переноси код между ними, не добавляй импорты через границу и не правь файлы чужого трека в задаче своего.
- Ищи существующий документ перед созданием нового; не создавай дубли и версии `final-v2`.
- Не добавляй новые корневые каталоги, зависимости и инфраструктуру без задачи, которая их требует.
- Не коммить секреты, токены, реальные персональные данные, кэши, логи и генерируемый мусор.
- Базовый сценарий решения должен работать без LLM. Данные отправляются во внешний API только после явного действия пользователя.
- Массовые изменения в MWS Tables требуют preview и подтверждения; повторный запуск не должен создавать дубли.
- После изменений запускай доступные проверки и сообщай, что именно было проверено.
